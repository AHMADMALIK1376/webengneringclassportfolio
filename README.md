# Web Engineering Class Portfolio

CSC 337 – Web Programming Languages · Assignment No. 1
Iqra University, Islamabad Campus (H-9)

A four-page professional portfolio built with **HTML5**, **CSS3** (one external file: `css/style.css`) and the **Bootstrap 5 CSS** grid/utilities. No JavaScript is used anywhere.

## Pages

| File | Page | Highlights |
|------|------|-----------|
| `index.html` | Home | Profile, live projects (FocusFlow, FinTrack), experience, skills, achievements, CV download |
| `hobbies.html` | Hobbies | Ordered + unordered lists, online & physical game, two styled tables |
| `media.html` | Favourite Media | CSS Grid two-column layout, social posts, 5 YouTube videos, local + online image |
| `contact.html` | Contact | Details, embedded Google Map, friends table, styled contact form |

## Featured projects

- **FocusFlow** – student productivity management system · https://focus-flow-two-pi.vercel.app/
- **FinTrack** – personal finance tracker · https://fintrack-y4wq.onrender.com/index.html

## CSS techniques

- Flexbox navigation bar, sticky header (`position: sticky`)
- CSS Grid for the Favourite Media two-column layout
- Styled tables with borders, background colours and hover effect
- Styled form fields with focus glow
- Media query so there is no horizontal scrolling at 375 px
